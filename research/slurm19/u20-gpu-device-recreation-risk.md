# u20 GPU device recreation risk

Read-only inspection on 2026-10-30 found that `/dev/nvidia0`, `/dev/nvidiactl` and `/dev/nvidia-uvm` currently have `other::---` ACLs and the ACL service is enabled. Both Slurm daemons depend on the oneshot ACL service. The tested current nodes are therefore protected for the previously checked identities; this says nothing about future nodes.

The installed `/etc/udev/rules.d/90-pro6000d-training-gpu.rules` invokes the ACL helper only for `add|change` events whose kernel name matches `nvidia*`. However, `udevadm info -q path -n` returned `Unknown device` for all three current compute/control nodes, and `/sys/dev/char/195:0` and `/sys/dev/char/195:255` were absent. Thus there is no evidence that these manually created device nodes produce the matching events. The installed NVIDIA vendor rule invokes `/sbin/ub-device-create` for the NVIDIA PCI driver and UVM module add events; the utility is an ELF binary from `nvidia-kernel-common-570`. The current driver parameter `DeviceFileMode` is decimal 438 (0666) with `ModifyDeviceFiles: 1`. This is an exposure risk if device nodes are recreated without the ACL service or another effective policy; it is not proof that recreation occurred or that a particular utility uses that parameter.

The oneshot service cannot by itself guarantee protection against later recreation after it has exited. Adding a later udev RUN action to the vendor's module/driver events may improve restoration but does not prove atomic, race-free denial while nodes are being created and does not cover every creator. Before claiming that unprivileged users cannot bypass scheduling across driver reloads or reboots, identify all node creators and establish restrictive creation permissions before access, then verify boot, reload and recreation paths in an isolated or controlled maintenance environment. Do not trigger a driver reload or recreate current devices while existing desktop/GPU work may be using them. No rules, devices, driver settings or services were changed in this inspection.
