# Staged MCP host consent adapter

By default `time-mcp` lists only read-only tools. If a trusted launching host provides an inherited, same-UID Unix stream as `TIME_MCP_CONSENT_FD`, the staged adapter can additionally expose submit and cancel. It sends the complete normalized broker method, path and body, plus a fresh nonce and SHA-256 digest, over that separate channel. Only a matching explicit host approval permits that specific broker mutation; an AI-supplied confirm field alone is not sufficient. Missing, denied, malformed or disconnected consent fails closed. Request IDs are recorded locally before sending and uncertain outcomes remain unknown.

A same-UID socket is not proof that a real human approved anything. The host must securely control the inherited descriptor, show the actual request to the person, and protect its response from the AI. No trusted UI or host integration is supplied by this patch, and env/FD possession must not be treated as authentication against arbitrary same-user processes. Other MCP mutations remain withheld. The adapter and installer have not been behavior-tested, and no running MCP has changed.
